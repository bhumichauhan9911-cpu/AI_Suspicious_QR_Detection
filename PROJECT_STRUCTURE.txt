AI-Based Suspicious QR Code Detection
======================================

app.py                 - Streamlit application
train_model.py         - Random Forest ML training
train_dl_model.py      - CNN Deep Learning training
requirements.txt       - Required Python libraries
README.md              - Project instructions
data/qr_dataset.csv    - Starter ML dataset
models/                - Trained model files are generated here

Run:
1. python -m venv venv
2. venv\Scripts\activate
3. pip install -r requirements.txt
4. python train_model.py
5. python train_dl_model.py
6. streamlit run app.py

The CNN is an educational demonstration using generated QR-like images.
